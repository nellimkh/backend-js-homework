# Chat Application with Node.js

## Նկարագրություն

Սա TCP Chat Application է, որը կառուցված է Node.js-ի ներկառուցված `net` մոդուլի միջոցով։

Ծրագիրը թույլ է տալիս մի քանի օգտատերերի միանալ նույն chat server-ին տարբեր terminal-ներից, ընտրել username, ուղարկել ընդհանուր հաղորդագրություններ և ուղարկել private message կոնկրետ օգտատիրոջ։

---

## Օգտագործված տեխնոլոգիաներ

- Node.js
- `net` module
- `readline` module
- TCP sockets

---

## Ինչպես է աշխատում ծրագիրը

Ծրագիրը բաղկացած է երկու հիմնական ֆայլից՝

- `server.js` — ստեղծում և կառավարում է chat server-ը։
- `client.js` — միանում է server-ին և թույլ է տալիս օգտատիրոջը հաղորդագրություններ ուղարկել։

Server-ը աշխատում է `3000` port-ի վրա։

---

## Username

Client-ը server-ին միանալուց հետո պետք է ընտրի username։

Դատարկ username-ը չի թույլատրվում։

Նույն username-ը միաժամանակ երկու օգտատեր չեն կարող օգտագործել։

Օրինակ՝ եթե `Bob` անունով օգտատեր արդեն միացած է, երկրորդ օգտատերը չի կարող ընտրել `Bob` անունը։

---

## Message Protocol

Մեր protocol-ում սովորական հաղորդագրությունը համարվում է broadcast message։

Եթե հաղորդագրությունը սկսվում է `/` նշանով, այն համարվում է command։

Օգտագործում ենք հետևյալ commands-ը՝

/who
/quit
/msg <username> <message>
